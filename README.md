# Moonspawn

A Unity 3D project developed in 2023, exploring 3D scene creation, visual composition, and digital artwork.

## Overview

Moonspawn is a personal 3D art project built using Unity. The repository contains the project files and a collection of renders produced during development.

## Project Setup

To open the project:

1. Clone the repository.
   ```bash
   git clone https://github.com/Venexs/Moonspawn.git
   ```
2. Open Unity Hub.
3. Add the cloned repository as an existing project.
4. Open it using a compatible Unity Editor version.
